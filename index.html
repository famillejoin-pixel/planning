ℹ️ Guide d'utilisation

Pour les secrétaires :
1. Configurez les paramètres ci-dessus (année, club, moniteurs, activités).
2. Cliquez sur un mois dans le menu ou ci-dessous pour accéder au planning.
3. Dans le planning mensuel, utilisez les listes déroulantes pour sélectionner les heures.
4. Les données sont sauvegardées automatiquement.
5. Consultez le bilan annuel pour voir les totaux et graphiques.
